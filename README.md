# **UI-UX-Experiment1**

## **Aim:**

To explore the fundamentals of **UI (User Interface)** and **UX (User Experience)**, differentiate between them using real-world case studies, illustrate their relationship in design, and demonstrate commonly used UI/UX design tools.

---

## **Algorithm:**

1. **Study Fundamentals**

   * Define UI (visual and interaction elements).
   * Define UX (overall usability and user journey).

2. **Differentiate UI and UX**

   * Use real-world case studies (Instagram, Spotify, Uber) to compare.
   * Prepare a comparison table.

3. **Illustrate Relationship**

   * Explain how UI and UX complement each other.
   * Use examples (Uber app) to show practical integration.

4. **Demonstrate Tools**

   * Explore Figma, Adobe XD, Sketch, Canva, InVision, Balsamiq.
   * Describe their purpose and usability in UI/UX workflows.

---

## **Output:**

* **Definitions:** Clear understanding of UI (appearance) and UX (experience).
* **Case Studies:**

  * Instagram → UI: layout, colors, icons; UX: easy posting, recommendations.
  * Spotify → UI: player design, buttons; UX: personalized playlists, smooth navigation.
* **Relationship:** UI is about how it *looks*, UX is about how it *feels*. Together they create a complete design.
* **Tools:**

  * Figma → Real-time collaborative design.
  * Adobe XD → Prototyping and animations.
  * Sketch → Design systems and UI kits.
  * Canva → Branding, logo, quick layouts.
  * InVision → Interactive prototypes, collaboration.
  * Balsamiq → Low-fidelity wireframes.

---

## **Result:**

The experiment successfully established a **practical understanding of UI and UX** by:

* Exploring fundamentals.
* Differentiating UI and UX using real-world applications.
* Showing their interdependent relationship in design.
* Demonstrating various professional tools used in the industry.

Thus, the experiment highlighted that **UI ensures visual appeal, UX ensures usability, and together they define user-centered design**.
